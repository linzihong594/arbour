# 需求与验收

版本：需求草案 v0.1。日期：2026-11-10。

“用户确认”表示来自本次对话的要求；“建议”表示为了推进规划提出的默认方案，仍可调整。七项功能均属于完整首版目标，分阶段实现不代表删去需求。

## 用户确认的功能

| ID | 需求 | 完整首版验收标准 |
| --- | --- | --- |
| FR-01 | Markdown 超文本编辑、即时预览 | 支持标题、粗体、斜体、链接、引用、列表、任务列表、代码块、表格；输入后即时显示格式效果。中文输入法、撤销/重做、复制粘贴正常。原生行内渲染与分栏预览的取舍见待定项。 |
| FR-02 | 界面优雅 | 完成日记列表、写作区、锁定态、地图选点和设置页；浅色/深色下均清晰，长标题和窄窗口不溢出；最终视觉由用户试用评价。 |
| FR-03 | 支持 iCloud 备份 | 用户可启用备份、看到实际备份状态；本地可离线写作；云盘不可用时保留本地数据并可重试；能从有效备份恢复。不能只完成复制功能而缺少恢复验证。 |
| FR-04 | 获取真实当前位置，也可地图选点 | 使用 Core Location 请求当前位置，保存获取时间、坐标与可用精度；支持地图手动选点、调整和取消。拒绝权限、定位失败和地图不可用时仍能写日记。不得以 IP 归属地或示例坐标冒充当前位置。 |
| FR-05 | 当前天气 | 对日记选定地点获取当前天气，保存气温、天气状态、来源和采集时间；失败时提示并可重试，不填造假数据；更换地点后避免显示旧地点天气。 |
| FR-06 | 单篇日记加密 | 列表保留标题，正文显示模糊占位与锁头；点击后输入密码解密；错误密码不可查看；重新锁定后不可通过预览、搜索摘要、辅助功能读取正文。磁盘、应用缓存和新备份中无该篇明文正文。 |
| FR-07 | Mac 指纹解锁 | 在支持且已配置 Touch ID 的 Mac 上，经系统指纹认证获取密钥并解密；认证取消或失败不解锁；不支持 Touch ID 或本机密钥失效时仍可使用日记密码。 |

## 用户确认的约束

- **轻量化**：优先降低安装体积、空闲资源占用和交互复杂度。
- **参考 GitHub 项目**：先调研可用实现与许可证，再决定具体复用方式。
- **先做项目管理，再开始开发**：管理文档已建立；用户于 2026-11-10 明确授权开始项目。
- **工程质量与交接**：做好项目结构，保持代码可读性，每次执行后提供下一次执行的提示词。

## 建议的最小使用闭环

新建日记 → 编辑并自动保存 → 可选添加位置/天气 → 可选加密 → 重新打开并解锁 → 备份 → 在隔离目录恢复。

同一天允许多篇日记；使用独立 ID，不能以日期作为唯一文件标识。基础管理包括修改标题、按时间浏览、标题搜索、移入废纸篓与恢复。以上为建议，避免为了完成七项功能却缺少基本可用性。

## 轻量化预算与测量口径

| 指标 | 初始目标 | 测量口径 |
| --- | --- | --- |
| 应用包体积 | 单架构 Release `.app` ≤ 30 MiB | 包含随应用分发的资源与框架；排除用户数据和系统自带框架；不以压缩包大小代替 |
| 空闲内存 | ≤ 100 MiB | 1,000 篇合成纯文本日记，选择普通日记，地图关闭，静置 60 秒；汇总应用及其子进程的物理内存占用 |
| 空闲 CPU | 60 秒平均 < 1% | 无输入、无备份任务、无网络请求；记录采样方法和硬件 |
| 冷启动 | ≤ 2 秒 | 进程未运行到可输入；相同数据集，至少 5 次，记录中位数与最慢值 |
| 预览响应 | 1 万字符日记输入后 ≤ 300 毫秒 | 使用固定脚本测 100 次编辑，记录 P95；同时人工检查中文输入法 |
| 后台行为 | 无自建常驻辅助进程 | 退出后不再定位、刷新天气或执行应用自己的备份；系统 iCloud 服务仍可能继续上传 |

这些是初始预算。M2 已完成本机合成库基准，结果见 [M2_VALIDATION.md](M2_VALIDATION.md)；不能将特定硬件与测试窗口的结果作为所有环境的承诺。预算调整须写入技术决策，不能默默放宽。地图打开时的峰值内存仍需后续测量。

## 首版建议边界

- 平台先做 macOS；Apple Silicon 优先，最低系统版本暂建议 macOS 14，等待依赖验证。
- 提供 Markdown 基础写作与本地文件备份；首版暂不加入 AI、协作、插件市场、复杂图表、音视频或多端客户端。
- 图片附件暂不纳入首版；引入时须同时解决附件加密、备份和内存预算。远程图片默认不自动请求。
- 以 iCloud **备份**为首版目标；多设备双向编辑、冲突合并与删除同步另列后续需求。
- 天气是供应方对指定地点和时刻提供的数据；补写历史日记时不能将当前天气标成历史天气。

| 密码模式 | 已采用逐篇设置密码及独立随机密钥 | M2 已定稿；共享密码管理未来另评估 |
