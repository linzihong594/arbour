# 栖木（Arbour）使用与发行说明（草稿）

更新：2026-11-20。对应项目：`mac-diary`（正式名称：**栖木 / Arbour**，当前 Release 构建产物：`build/栖木.app`，逻辑体积约 `7.95 MiB`）。

> 本文件为 M6 `REL-001` 的首版使用说明草稿；签名与公证状态按当前实机事实记录，不将本地开发签名冒充为公证发行版。

## 1. 安装与运行

### 本地构建与启动

```sh
python3 scripts/manage.py build
# 启动独立示例库（不影响本地真实日记）
open -n "./build/栖木.app" --args --demo
# 启动正常本地库（首次启动为空）
open "./build/栖木.app"
```

### 签名与公证状态

- **当前状态**：本机源码构建默认使用本地 ad-hoc 签名（无 Apple Developer ID 公证，未上架 App Store）。
- **Touch ID**：需使用已注册 Bundle ID 的 Apple Development（或 Developer ID）证书与有效 macOS provisioning profile 重新签名后，方可使用受保护的 macOS Keychain 生物识别解锁。密码加密功能在本地 ad-hoc 签名下完全正常可用。
- **首次打开**：若经由他人分发且未经公证，macOS Gatekeeper 会拦截启动；当前阶段仅供本机自行构建与预览。

## 2. 日记树主页与沉浸写作

- **日记树主页**：
  - 你的每一篇日记都会化作一块木牌挂在树枝上；随着日记篇数增长，大树会从 **幼苗（0 篇）→ 小树（1–10 篇）→ 繁茂大树（11–50 篇）→ 参天古树（51–200 篇）→ 记忆巨木（200+ 篇）** 真实拔高并长出更多带叶枝丫（单页主枝容量从 3 块增至 22 块，超出部分以远景微缩木牌缀满树冠，放大至 `≥ 1.40×` 自动在视野内展开为可点击木牌）。
  - 支持双指捏合、双击、`⌘+` / `⌘-` / `⌘0` 及右下角胶囊在 `70%–260%` 间缩放并拖拽漫游。
  - 树叶色彩随当前月份自动呈现春/夏/秋/冬四季色板，天空与日月随晨曦/白昼/黄昏/深夜自然流转，并可按当天位置同步晴/多云/雾/雨/雪/雷雨场景（右上角天气胶囊支持手动预览天气、树龄与季节）。
  - 对任意挂牌右键可直接 **打开日记**、**加密/解锁**、**导出 Markdown**（私密日记需先解锁）或 **移入废纸篓**（木牌断绳坠落消散，数据安全保留在废纸篓中，随时可恢复）。
  - 底部「全部时光」胶囊支持按年份或月份快速定位树冠上的日记。
- **沉浸式信纸阅读与写作**：
  - 点击挂牌或「写一篇」进入静态虚化树影背景下的居中书页界面（写作时树动画完全停止，零额外动画 CPU）。
  - 支持原生 Markdown 即时渲染与原文切换、350 ms 防抖原子自动保存、按需单次定位与地图手选（请求结束立即停止定位，不后台追踪）、按地点获取当天天气快照。
  - 点击左上角抽屉图标可随时展开轻量化侧滑目录，进行标题搜索、自然日筛选与废纸篓恢复。

## 3. 单篇加密与密码恢复边界

- **加密范围**：单篇加密使用每篇独立口令派生密钥，对持久化正文（及位置/天气等正文载荷）加密；列表标题、自然日与元数据保持明文以便树冠挂牌与标题搜索，不建立正文搜索索引，也不生成临时明文文件中转。
- **锁定态**：退出重开、手动锁定或系统锁屏后，私密日记仅显示锁定占位，无法从预览、摘要或旧撤销栈读取正文。
- **密码丢失无法恢复**：本应用无账户系统、无云端密钥托管、无重置密码通道。**如果遗忘单篇日记的加密密码，该篇密文正文将永久无法解密**（开启 Touch ID 仅在本机 Keychain 生物识别有效且指纹集未变更时提供便捷解锁，不能替代密码备份）。
- **历史备份中的明文风险**：若一篇日记曾以明文形式写入过早期备份快照，随后才启用加密，早期快照中仍会保留当时的明文副本；请按需手动清理旧备份目录。

## 4. 备份与隔离恢复

- **不可变快照**：在备份面板选择目标目录（如 iCloud Drive 中的专用文件夹或本地外置目录）后，应用以安全书签记住授权，并在每次备份时写入独立不可变快照（含 `Entries/`、`Trash/`、`manifest.json` 逐文件 SHA-256 与 `COMPLETE` 完成标记），默认保留最近 5 个完整快照，不覆盖旧快照。
- **本地写入与云端上传分离**：面板会如实区分「已写入本地目录」「等待 iCloud 上传」「已上传」与「目录不可用」状态；不会把本地写入冒充为云端同步完成。
- **隔离目录恢复**：恢复操作必须选择一个**空目录**，应用会先校验 `COMPLETE` 标记与每个文件的 SHA-256，拒绝半成品、篡改、清单外文件与非空目标，失败自动回滚，绝不直接覆盖当前日记库。恢复后保留原 UUID 与加密容器，私密日记可仅凭原密码在新目录或新设备独立解密。
